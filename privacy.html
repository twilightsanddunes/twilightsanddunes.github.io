Privacy Policy

Last updated: November 1, 2026

TSD YT Uploader is a private application operated by twilight sand dunes. It is used only to upload and schedule videos, thumbnails and playlists on the twilight sand dunes YouTube channel.

Data we access

With the channel owner's permission, the app uses the YouTube Data API to upload videos, set video details and thumbnails, and manage playlists on that channel. It does not access any other user's data.

How data is stored

Sign-in tokens are stored only on the operator's own computers. No data is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
